About Me

I'm Abdullah, a 2nd year IT student at SLIIT specialising in Artificial Intelligence. I actually started coding before university by doing Harvard's CS50 courses online, and that's what got me really into programming.

I mostly build web apps with Spring Boot and React and mobile apps with Flutter, and lately I've been getting into machine learning with Python. I've also done a few hardware projects with Arduino and ESP32.

I'm still learning a lot and I like to understand how things actually work behind the scenes. I'm also an IEEE Student Member and I try to join coding events and workshops whenever I can.

Right now I'm looking for internships where I can work on real projects and learn more.
